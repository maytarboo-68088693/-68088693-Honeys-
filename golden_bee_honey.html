เชื่อมต่อ Google Apps Script Web App URL เพื่อให้ข้อมูลออเดอร์ส่งเข้า Google Sheet ทันที

1. เชื่อมต่อ Google Apps Script Web App URL

ยังไม่ระบุ URL

วางลิงก์ Web App URL ที่ได้จากการ Deploy Google Apps Script (ลงท้ายด้วย /exec) ระบบจะบันทึกไว้ในเบราว์เซอร์และส่งข้อมูลเข้า Google Sheet ทุกครั้งที่มีการสั่งซื้อ

2. โค้ด Google Apps Script (สำหรับวางใน Google Sheet)

หัวตารางใน Google Sheet แถวที่ 1 (A1:J1): OrderID | Timestamp | CustomerName | Phone | Address | ZipCode | SKU1_Qty | SKU2_Qty | TotalPrice | OrderSummary 

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  sheet.appendRow([
    data.orderId,
    new Date(),
    data.name,
    "'" + data.phone,
    data.address,
    "'" + data.zipcode,
    data.sku1,
    data.sku2,
    data.total,
    data.summary
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({ "result": "success" }))
    .setMimeType(ContentService.MimeType.JSON);
}

3. โครงสร้างไฟล์สำหรับ GitHub & Vercel (ตามโจทย์ 008)

โครงสร้าง Repository บน GitHub:

honey-shop-008/
├── index.html          (หน้าเว็บหลัก)
└── images/             (โฟลเดอร์เก็บรูปแยกต่างหาก)
    ├── honey1.svg      (รูป SKU: HONEY-01)
    └── honey2.svg      (รูป SKU: HONEY-02)

ขั้นตอนส่งงานขึ้น Vercel:

  1. สร้าง Repository ใหม่บน GitHub และอัปโหลด index.html กับโฟลเดอร์ images/
  2. เข้าเว็บ vercel.com ล็อกอินด้วย GitHub
  3. กด Add New > Project แล้วกด Import โปรเจกต์
  4. กด Deploy จะได้ลิงก์โดเมน .vercel.app สำหรับส่งอาจารย์ทันที
